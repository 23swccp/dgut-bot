# 字迹生成器字体

字体文件仅转换或保留原有字形格式，依 SIL Open Font License 1.1 随程序分发；各字体完整许可见同目录 `*-OFL.txt`。字库覆盖清单 `coverage.json` 从字体 Unicode cmap 生成，用于缺字提示。

- `xiaolai.woff2`：小赖字体，来源 https://github.com/lxgw/kose-font ，样本来自 https://github.com/kinrooo/chinese-handwriting-generator/tree/main/assets/fonts/xiaolai 。
- `longcang.woff2`：龙藏体，来源 https://github.com/google/fonts/tree/main/ofl/longcang 。
- `cef.woff2`：快去写作业，来源 https://github.com/Partyb0ssishere/cef-fonts-cjk 。
- `maoken.woff2`：猫啃硬笔楷书简体版 0.20，来源 https://github.com/maoken-fonts/MaokenYingBiKaiShuJ 。
