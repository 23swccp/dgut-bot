<h1 align="center">dgut-bot</h1>
<p align="center">莞工小皮卡</p>
<!-- github-readme-header:end -->

**莞工小皮卡**是一款主要由 `Python` 编写的优学院辅助程序，能够辅助处理课件学习任务。仅支持 Windows 系统。

> 不同的 Chromium 内核浏览器可能导致刷课功能异常，应优先使用谷歌 Chrome 或 Microsoft Edge 浏览器。

启动后先在终端检测浏览器；未找到时会弹出文件选择窗口，请选择浏览器的 `.exe` 文件（如 `msedge.exe` 或 `chrome.exe`）。取消选择后也可在终端粘贴程序路径或安装文件夹，按回车重新选择，输入 q 退出。确认有效后才打开网页。后续登录等操作务必在程序打开的浏览器进行，**不要新开另一个进程的浏览器**。

登录成功后自动缓存 24 小时：用 `login-cache.json` 保存登录凭据、必要身份信息和时间戳，不保存密码。下次启动会先尝试恢复并向学校验证，有效时直接进入课程列表；重启不会延长同一份缓存的有效期。缓存超过 24 小时或被服务器明确拒绝时失效；短暂网络故障保留缓存供重试。浏览器里新登录的账号优先，不读取旧 `auth.json`。缓存不能保证学校会话一定维持 24 小时，学校提前注销凭据后仍需重新登录。

打开浏览器界面时，模块侧边栏默认展开；点击右上角按钮可收起或再次展开。

关闭最后一个小皮卡或 AI 工作台页面后，后台服务会自动退出。页面未能连接或关窗通知丢失时，无活动任务的服务最多等待两分钟再退出；仍打开的后台页面和活动 Agent 任务会保留服务。

## 课件学习

刷课模块用于辅助处理课件中的视频、文档、章节切换和提示弹窗。进入模块后，程序会在登录有效时自动扫描当前课程中的未完成课件；默认同时扫描 3 门课程，每完成一门就立即显示，可直接选择课件，无需等待其他课程。

成功结果按课程在本次登录会话内缓存约 5 分钟，普通扫描只补读失败、缺失或过期的课程；“重试失败课程”使用此规则。“重新扫描”强制更新全部课程，更新期间保留旧列表并逐课替换，读取失败的课程移除旧结果并显示原因。切换账号或登录失效会清除缓存。取消在当前请求结束后的边界生效，不再请求后续教材或课程，也不会追加迟到结果；当前请求结束后可重新扫描。

- 在“未完成课件”区域可按课程名、章节名或课件名搜索，使用鼠标或 `↑` / `↓` 与 `Enter` 选择一个课件。
- 选择后程序会复用程序管理的优学院课件标签页，依次显示“正在打开、等待页面加载、正在校验、正在启动”等状态；只有 URL、页面结构和课件标识校验通过后，才会调用现有刷课控制器一次。
- 某门课程扫描失败不会阻止其它课程；可展开失败详情并点击“重新扫描”。扫描中可以取消，明确刷新会绕过五分钟缓存。
- 第一版只支持一次选择并启动一个课件，不支持批量选择或连续自动刷完全部课程。

如果目录响应暂未提供可验证的真实课件地址，或自动打开失败，仍可使用原有手动方式：

- 使用程序启动的 Chromium 浏览器登录优学院。
- 进入课程并打开需要学习的具体课件页面。
- 确认页面地址中包含 `ua.dgut.edu.cn/learnCourse`。
- 如果启用了自动答题，程序会优先使用本次运行中已验证的登录会话直接连接课程 AI，无需另开 AI 工作台；会话不可用时退回浏览器中的课程 AI 上下文。

![打开到这样子的页面](./docs/course-page.png)

- 然后返回程序的刷课模块，按 `Enter` 或输入 `start` 启动。

### 查看运行状态

运行期间，状态区域会显示当前课程、课件页面、视频进度、任务计划、重试次数和停滞状态。课件页面可以留在后台，程序会继续处理已连接的页面。

测验提交并确认完成后，程序会继续检查同页视频和文档；全部完成且开启自动翻页时，才进入下一页。作答失败、停止任务或切页后，不会由旧答题任务触发翻页。

### 自动答题

自动答题默认关闭，需要在设置 → 刷课中为本次运行明确启用。开启总开关后，可以分别启用选择题、判断题和填空题。成功启动一次刷课任务后，总开关会立即恢复为关闭；当前任务仍按启动时的选择运行，下次启动则需要重新开启。

程序会把当前页面的一份测验的纯文本题干、选项和答案格式约束交给课程 AI，支持单选、多选、判断及多空填空；“选择题”开关同时控制单选和多选。收到结构化 JSON 后，程序先校验题数、选项范围、重复选项和填空数量，再逐题填写、核对，最后整套提交一次。限时测验会先点击“开始答题”，待题目显示后提取。日志会显示取题、请求 AI、格式校验和填写进度，不记录题目或答案正文。

等待 AI 期间如果停止、重新启动任务、切换页面或题目发生变化，旧答案不能用于填写，程序会停止等待人工检查。当前测验处理结束前不会并发启动另一份测验，也不会自动翻页。AI 桥接操作全局串行，相邻两次上游操作在上一轮结束后至少间隔 5 秒。题目中的图片和公式暂不传给 AI；运行日志会提示这类信息缺失。多选的 DOM 契约已用本地合成页面验证，真实平台仍待人工验证。

程序内的独立 AI 工作台提供首选模型选择，下拉列表来自优学院当前启用的模型；选择会自动保存，并同时作为刷课自动答题的首选。只要本次运行已从浏览器登录并读取课程，就能直接使用独立工作台。

刷课答题和 AI 工作台都会自动切换模型：先使用首选，失败后优先尝试已启用的本地文字模型，再按平台顺序尝试其他文字模型和视觉模型。额度耗尽、网络或服务错误直接换模型；测验答案格式不合格时，同一模型最多修正一次，再继续切换。切换记录会显示原因和模型，工作台每条回复也会显示实际使用的模型；自动切换不改保存的首选。切页、停止任务或已开始填写时不会启动新模型来重做。

如果提示模型“每日 token 数或联网搜索次数已用完”，表示该模型上游额度耗尽，可以在 AI 工作台选择其他可用模型后重试。2026-10-25 已在一份真实 7 题限时测验中验证通义千问返回 JSON、程序回填并单次提交成功，平台判定 5 对 2 错；格式正确和提交成功不代表答案全部正确。

> 自动答题只使用课程 AI 反代和自动模型切换。所有已启用模型都失败、答案持续无法通过校验，或遇到不支持的题型时，会停止当前刷课任务，保留页面等待人工处理，不猜选项、不填占位内容、不提交未验证的答案。页面填写开始后若出现错误同样停止。当前页只有未启用的题型时停止等待人工完成，不显示提交成功。

> 课程 AI 请求和测验提交都可能由学校或平台记录。刷课只对已经校验的页面操作加入有限的鼠标轨迹和短停顿；课程查询经 Chromium 页面请求，但这些措施都不能保证自动化行为不可识别。

## 作业

进入程序侧边栏的“作业”后，程序会扫描当前账号的全部课程，并按课程列出作业及其状态：未提交、未互评、互评中、已批阅，其它状态显示为带原始数值的兜底文案。清单默认只显示“待处理”（未提交与未互评），可切换到“全部”“已批阅”或“已归档”；含待处理作业的课程默认展开，其余课程默认收起，同一课程内按待处理优先、截止时间升序排列。

每条作业显示标题、教师、截止时间与状态；已过截止时间的待处理作业会标记“已截止”。点击“打开页面”会在程序浏览器中打开该课程的作业列表页。状态为“未互评”或“互评中”的作业可以点击右侧下拉三角展开匿名作业的评分和评语。

课程标题和每条作业都提供归档按钮。归档后的课程或作业不再出现在“待处理/全部/已批阅”，可在“已归档”中恢复；归档整门课程会同时隐藏该课程以后新增的作业。归档保存在本机并按当前登录账号隔离，刷新或重启后仍然有效；归档作业不会进入互评 100 分批量提示。

扫描允许单门课程失败，结果在本次运行中缓存约五分钟，也可以点击“扫描全部课程”强制刷新。

## 课件导出

打开侧边栏“课件导出”，首次默认显示当前学期，初始不勾选。可以按课程名、教师或 ID 搜索，逐门勾选、Shift 连选、全选当前列表、逐项移除或清空选择，并切换历史或全部学期。搜索和切换学期时保留勾选，右侧显示完整所选清单。浏览器只记忆学期筛选，不保存勾选；同名课程按 ID 分开显示，导出选择与签到单选相互独立。按 `/` 聚焦搜索，`Esc` 清空或退出搜索。

选课后，在“导出内容”里勾选资源区、课件区、作业与互评，并选择正文、文档/PPT、图片、音频、视频、字幕或其他附件；默认全部勾选。例如只选“课件区”和“文档/PPT”，即可跳过视频和作业。点击“读取目录并选择”后，可搜索、逐项勾选章节或作业，并全选或清空当前可见目录项；资源区按整区选择。切换范围或搜索保留目录勾选，增减课程会重置目录选择，需要重新读取。未选章节不读取正文，未选类型不下载附件；类型按文件名或 URL 扩展名判断，未知格式归“其他附件”。正文开关控制是否保留页面原文，关闭后仍生成所选附件的 Markdown/HTML 索引页。“读取目录”只查询全部来源的目录元数据，不下载附件；实际导出时按范围读取。正文中未下载的资源保留来源链接。

学期根据课程名明确标注的春/秋季或学年学期识别；平台当前没有学期字段。名称未注明学期的课程暂归本期并标记，供用户自行取舍。当前学期按本地日期确定：2–7 月为当年春季，8 月至次年 1 月为秋季。

课件导出读取课程资源区及该课程的所有教材，将正文、图片、文档和音视频保存到 `courseware/<课程名>/`。资源区会翻页并进入文件夹；每章一个 `NN_章节名/` 文件夹，每页生成同名的 `.md` 与 `.html`，附件放在 `_files/NN/` 中，并接入正文的本地链接。文档课件会嵌套在查看器 iframe 里，导出时从 `docs.ulearning.cn?furl=` 解析出真实文件再下载。课程目录为 `index.md`，来源、文件路径和失败详情记录在 `manifest.json`。

同次导出也保存该课程的作业。作业放在 `courseware/<课程名>/作业/<作业ID_标题>/`，分别保存题目与要求、本人当前提交（含草稿）、收到的可见互评反馈、分配给本人的互评作业和评分规则。教师提供的文件、本人提交附件、互评对象的附件及正文内图片、媒体均沿用同一下载器；每份材料有独立目录、Markdown/HTML 和 `_files/01/`，同名附件不会混放。互评对象按平台返回的互评标识保留独立目录，不附加其姓名与学号。作业列表会翻页，包含本机列表中已归档隐藏的作业；读取或下载失败在原有失败详情和清单中显示。导出只读取内容，不提交作业或互评分数；未公布的本人评分与反馈不导出。

**测验块在解析阶段跳过**，不写入题目、选项或答案，也不发出作答请求；资源区的试题、试卷类型不读取详情。外部平台跳转保留链接，平台未开放下载的资源会注明。普通文件直接保存；旧视频原件失效时尝试平台播放器的 MP4 版本。完结 HLS 选择最高带宽视频与默认音轨，下载分段、初始化文件及密钥后在本地封装为 MP4，需要安装 FFmpeg 并加入 PATH；尚未完结的流会列入失败详情。

同一页中学校资源主机别名和认证查询参数不同的同一附件合并下载，正文统一改写本地地址；每页保留独立附件目录。

- 点击“导出所选”后按课程列表顺序串行导出，逐课显示章节、页面、附件数量、保存目录与失败详情。当前选择全部成功后，按钮变为不可点击的“已导出”；调整课程、范围、章节或类型后可再次导出，失败或取消后可重试。队列正常结束时自动打开一次保存文件夹：一门课打开该课程目录，多门课打开课件总目录；完成区也可点击“打开文件夹”。打开文件夹失败会显示原始错误，导出结果仍保留。普通失败继续下一门；登录失效或“停止队列”会停止后续课程，已保存内容保留。停止在工作边界生效，正在处理的文件会先结束。
- 后端命令：`get_courseware_export_catalog`（`courseIds`，只读目录）、`start_courseware_export`（参数 `courseIds`，LMS 课程 ID 数组；兼容单个 `courseId`；可带 `options` 筛选）、`get_courseware_export_status`、`cancel_courseware_export`。
- 状态字段包含队列 `state`（`idle`/`running`/`cancelling`/`completed`/`cancelled`/`error`/`auth_required`）、`courseTotal`/`courseDone` 和逐课 `results`；课程状态另含 `queued`/`skipped`，记录章节与页面进度、附件数量、失败原因和最终目录。页面重新进入会读取当前后端队列结果，后端重启后需重新选择并启动。
- 正文相同则跳过写入；来源身份和已知大小均相同的附件复用本地文件，其余重新下载。附件来源只保存哈希，不保存认证 URL；旧资源库首次重跑会重新确认附件。单个入口或附件失败会记录原因；失败、取消或按类型筛选的重跑保留未刷新的目录记录，不会清理此前已导出的资料。
- 优学院课程 ID 与 LMS 课程 ID 不通用，教材入口会显式换算标识。没有教材的课程仍可导出资源区；缺失教材标识会记入学习页失败详情。

界面截图使用真实组件和合成数据：[课程选择](docs/courseware-export/selection.jpg)、[导出进度](docs/courseware-export/progress.jpg)。纯解析性能基准可运行 `python backend/tools/benchmark_courseware.py`，输出样本大小、每页耗时、吞吐量及运行环境。

## 设置与数据

### 浏览器

用于选择程序连接的 Chromium 浏览器。通常保持自动检测即可；只有自动检测失败时才需要填写浏览器路径。

### 校园网

启用“开机时打开校园网登录页”并保存设置后，程序会在当前用户的注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 中创建 `DgutBotCampusLogin` 启动项；关闭开关并保存后会移除该项。开机后，它会立即使用默认浏览器打开 `https://login.dgut.edu.cn/eportal/index.jsp`。该功能不等待网络、不判断当前是否已联网；



### 本地数据

| 文件或目录 | 用途 |
| --- | --- |
| `config.json` | 保存浏览器和刷课设置；自动答题开启状态除外 |
| `browser_profile/` | 保存独立浏览器配置和登录状态 |
| `data.md` | 运行日志：事件流、命令调用、签到详情与错误原因，供出问题后按时间回看 |
| `courseware/` | 课件导出的本地资源库：按课程的 Markdown、HTML、附件与清单 |
| 注册表 `DgutBotCampusLogin` | 可选的当前用户校园网登录页开机启动项 |

`data.md` 默认记录完整运行过程：每一次界面事件（轮次、签到成功/跳过/失败、警告）按 `时间 · 级别 · 分类 · 内容` 写成一行，每次命令调用另记一行（只记录 payload 的键名，不记录取值），签到提交的 HTTP 状态与业务响应作为缩进明细。凭据类字段写入前会替换成 `[已隐藏]`。文件超过 2 MB 时轮转为同目录的 `data.1.md`，只保留一份历史。路径和开关都能在设置页“日志与数据”里改；关掉开关就不再写文件。

同样的内容在侧边栏 **运行日志** 页可实时查看：签到、刷课、课件导出、作业、程序、更新的记录合并成一条完整时间线，默认跟随最新（可暂停、可手动刷新），不做筛选。点“导出日志”会把整份日志另存成 `日志导出-年月日-时分秒.md` 并给出打开入口，方便出问题时把整段过程发给维护者。

程序的本地服务只监听 `127.0.0.1`；发行版端口范围为 `8765–8784`，开发前端为 `1420–1439`。

## 更新

小皮卡通过系统代理读取 GitHub Release 的更新清单，由 Velopack 比较版本；检查版本不占用 GitHub API 额度。网络短暂失败会自动重试一次；启动时尚未联网，会在约 30 秒、120 秒后各重试一次。检查失败不影响当前版本运行，可在设置页查看原因并重新检查。

本次改进说明优先读取对应版本的 GitHub Release 正文；维护者编辑正文后，下次成功检查说明时会同步到弹窗。正文按 Markdown 显示，支持标题、列表、表格、图片和折叠内容；完整链接、`#编号`（Issue / PR）及 `@用户名` 均可点击跳转。说明获取失败会使用上次缓存或更新包自带说明，不影响发现、下载和安装新版。更新包下载同样使用系统代理，仍由 Velopack 校验与安装。

发现新版时，会弹出居中的更新窗口，展示新旧版本和本次改进说明；点击“下载更新”才开始下载，选择“稍后”则继续当前任务。下载进度、错误和安装操作都在同一窗口中显示，下载校验完成后可选择“立即更新并重启”。同一版本的同一阶段在当前页面会话中只自动提示一次，刷新也不会反复提醒；可从“设置 → 软件更新 → 查看更新”重新打开。安装会停止当前任务并自动重启。界面不再使用更新铃铛、消息抽屉或浏览器原生确认框。

安装器和更新均通过 [GitHub 发布页](https://github.com/23swccp/dgut-bot/releases/latest) 提供。若旧版无法检查更新，可下载完整安装器覆盖升级；网络连接失败或下载较慢时，请检查系统代理或开启支持 GitHub 的网络加速器后重试。源码运行可以检查更新，但不支持自动安装；若安装版提示缺少安装信息，请使用完整安装器重新安装。
